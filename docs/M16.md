## Decisions

- **Only `PROVEN` findings are SARIF results.** A claim whose proof did not hold
  is not an alert; it remains in `verdict.json` with its state. Code scanning
  should show defects, not unsettled claims.
- **SARIF is a second output, not a replacement.** `verdict.json` keeps the
  complete evidence, including refuted and unsettled findings and the run's
  context; the SARIF log is the portable alert format.
- **The license is not a guess.** MIT is the recommendation for a tool of this
  size, but choosing a license is the owner's decision; the wheel carries no
  license field until that decision is made.
- **Quickstart names the three artifacts honestly.** The wheel has no sandbox,
  the image has no reviewer, and the action has no Hermes installer; each
  section says what the user must bring.
