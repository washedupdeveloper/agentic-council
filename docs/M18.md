# M18 — Sandboxed, ephemeral execution

A review must not leave anything on the host it did not explicitly choose to
leave. On NixOS the tool has `bwrap`; this milestone uses it for the reviewer as
well as the proofs, and adds a zero-footprint run mode.

## Scope

1. **Reviewer sandbox.** With `bwrap`, the reviewer runs with an immutable root,
   a private `/tmp`, and a tmpfs overlay of `$HOME`. It can read the host and
   reach the model; writes to `$HOME` or `/tmp` vanish with the process. The
   prompt directory and the reviewer binary are bound back read-only because the
   private `/tmp` would hide them. `verdict.json` records `reviewer_sandbox`.
   The default is **on when bwrap is on PATH**; `--sandbox` requires it and
   fails without it; `--no-sandbox` opts out. A bare wheel without bubblewrap
   records `false` rather than pretending.
2. **Ephemeral runs.** `--ephemeral` places the run directory in a private
   temporary tree and removes it after the verdict; `--keep DIR` copies the run
   there first. The verdict is printed and SARIF is written before removal. A
   failed run removes its temporary tree too; if `--keep` cannot copy, the
   evidence is left in place and its path printed.

## Live evidence

`council review -C /tmp/sarif-repo --base HEAD --samples 1 --reviewer <stub>
--no-stream --sandbox --ephemeral --keep /tmp/m18/kept --run-id eph
--sarif /tmp/m18/council.sarif`

- verdict `FAIL`, exit 1, one proven critical finding;
- `/tmp/m18/kept/eph/verdict.json` and `sample-1.json` exist;
- `/tmp/m18/council.sarif` has `security / error`;
- `/tmp/sarif-repo/.council/runs` contains older runs only, no `eph`;
- the temporary tree named in the report no longer exists.

Hermes itself was also run inside the same bwrap shape (`hermes --version`, and
a one-line `chat` answering `ok` in 21 s), so the sandbox is not merely a fake
binary path.

## Decisions

- **Overlay the home, do not chroot.** bwrap's `--overlay-src $HOME
  --tmp-overlay $HOME` is rootless, keeps the host readable and the model
  reachable, and discards every write. A chroot would need root and would hide
  the Nix store and the Hermes configuration.
- **Auto, but recorded.** Sandboxing on when bwrap exists gives NixOS users the
  safe path without breaking a bare wheel; `reviewer_sandbox` makes the choice
  visible in the evidence. `--sandbox` is the strict form that fails instead of
  falling back.
- **Ephemeral is opt-in — for one milestone.** M19 made it the default: the run
  directory is now a temporary tree unless `--no-ephemeral` or `--keep` asks for
  it. The reasoning below is M18's, kept as the record of the reversal.
- **Cleanup is part of the success path.** The temporary tree is removed after
  the verdict is printed and SARIF is written; a failed run removes it too. If
  the copy fails, the evidence is not deleted.
